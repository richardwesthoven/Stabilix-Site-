# Stabilix AerFrame Billing Calculator

This repo contains a React + Vite app for the Stabilix AerFrame billing and ROI calculator.

## Getting started

```bash
npm install
npm run dev
```

Open the URL printed by Vite (default `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Notes

- The calculator UI and logic live in `src/App.tsx`.
- Global styles are defined in `src/styles/globals.css`.
